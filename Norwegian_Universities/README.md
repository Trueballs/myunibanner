# Norske Universiteter - Campus Fotografier

Dette er en systematisk samling av autentiske fotografier av norske universiteter og deres campuser, organisert etter universitet og studiested/by.

## 📁 Mappestruktur

```
Norwegian_Universities/
├── university_campus_images.md          # Hovedoversikt over alle bilder
├── README.md                            # Dette dokumentet
├── UiT/                                 # Norges arktiske universitet
│   └── campus_images.md                 # Bilder: Tromsø, Alta, Harstad, Narvik
├── BI/                                  # Handelshøyskolen BI
│   └── campus_images.md                 # Bilder: Oslo Nydalen, Bergen, Trondheim, Stavanger
├── HINN/                                # Høgskolen i Innlandet
│   └── campus_images.md                 # Bilder: Lillehammer, Hamar, etc.
├── NMBU/                                # Norges miljø- og biovitenskapelige universitet
│   └── campus_images.md                 # Bilder: Ås
├── Nord/                                # Nord universitet
│   └── campus_images.md                 # Bilder: Bodø, Levanger, Steinkjer, etc.
├── OsloMet/                             # Storbyuniversitetet
│   └── campus_images.md                 # Bilder: Oslo Pilestredet, Kjeller
├── USN/                                 # Universitetet i Sørøst-Norge
│   └── campus_images.md                 # Bilder: Drammen, Horten, Ringerike, etc.
├── UiA/                                 # Universitetet i Agder
│   └── campus_images.md                 # Bilder: Kristiansand, Grimstad
├── UiB/                                 # Universitetet i Bergen
│   └── campus_images.md                 # Bilder: Bergen sentrum
├── UiO/                                 # Universitetet i Oslo
│   └── campus_images.md                 # Bilder: Oslo Blindern
└── UiS/                                 # Universitetet i Stavanger
    └── campus_images.md                 # Bilder: Stavanger Ullandhaug
```

## 📸 Format

Hver markdown-fil inneholder:

```
## [By/Campus]

1. **[Bildebeskriving]** 
   - [Direkte URL til bildet]

2. **[Bildebeskriving]** 
   - [Direkte URL til bildet]
```

## 🔗 Kilder

Alle bilder er hentet fra:
- **Wikimedia Commons** (commons.wikimedia.org) - Åpen kildekode, CC-lisensiert
- **Wikipedia** (wikipedia.org / wikipedia.no)
- **Universitetenes egne nettsider** og mediebiblioteker

## ✅ Autentisitet

Alle bilder er **autentiske fotografier**, IKKE AI-genererte:
- Hver bildefil har fullstendig metadata (kamera, dato, GPS-koordinater)
- Lisensiert under Creative Commons eller offentlig domene
- Opprinnelseskilde er dokumentert og verifiserbar

## 📖 Bruk

1. **Se alle bilder på en gang**: Les `university_campus_images.md`
2. **Se bilder for ett universitet**: Åpne mappen og les `campus_images.md`
3. **Direkte bildelenker**: Alle lenker i dokumentene peker direkte til bildefiler
